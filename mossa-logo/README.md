# Mossa Logo

Interactive p5 logo prototype for Mossa.

- Press `1` through `8` to switch animation modes.
- Click the mode pills, color pills, or `R` randomizer to change behavior and palette.
- Click the stage in modes `5` and `7` to trigger the drop or scatter interaction.

[View experiment ->](https://bergerfohr.github.io/lab/mossa-logo/)
