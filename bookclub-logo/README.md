# Bookclub Logo

Interactive SVG logotype prototype for Bookclub.

- Mode 1: Click to ripple the full logotype between Serif and Sans from the click origin.
- Mode 2: Serif drawing by default; hovering an individual letter swaps only that letter to Sans.
- Press `1` or `2` to switch modes. Press `g` to toggle hit-area guides.
