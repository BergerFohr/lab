# Bookclub Logo

Interactive SVG logotype prototype for Bookclub.

- Mode 1: DVD-style drift; the full logotype bounces around the viewport and switches between Serif and Sans on each edge hit.
- Mode 2: Click to ripple the full logotype between Serif and Sans from the click origin.
- Mode 3: Serif drawing by default; hovering an individual letter swaps only that letter to Sans.
- Mode 4: Scrub; drag the 1px handle across the logo-width line to control left-to-right Serif/Sans progress.
- Press `1`, `2`, `3`, or `4` to switch modes. Press `g` to toggle hit-area guides.
