# Bookclub Logo

Interactive p5/SVG logotype prototype for Bookclub.

- Mode 1: Serif drawing by default; hovering an individual letter swaps only that letter to Sans.
- Mode 2: Press `2`, then move the mouse anywhere on the page to dynamically swap one full letter from Serif to Sans based on cursor position and motion.
- Press `1` or `2` to switch modes. Press `g` to toggle hit-area guides.
