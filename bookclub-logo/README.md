# Bookclub Logo

Interactive p5/SVG logotype prototype for Bookclub.

- Mode 1: Sans drawing by default; hovering an individual letter swaps only that letter to Serif.
- Mode 2: Press `2`, then move the mouse anywhere on the page to trigger a dynamic whole-word Sans/Serif transition.
- Press `1` or `2` to switch modes. Press `g` to toggle hit-area guides.
